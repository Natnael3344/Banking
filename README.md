# Banking

A simple **Flutter** mobile app that simulates a bare-bones bank teller UI: a
list of customers with balances, a detail view for each customer, and a
screen for transferring a fixed amount to any customer in the list. There is
no backend, no persistence, and no real money movement — all customer data
lives in an in-memory list inside the app, so every change resets when the
app restarts.

## What it actually does

- Shows a landing screen with a "Start" button that opens the customer list.
- Lists 10 hard-coded customers (name, email, balance) on the **Customers**
  screen.
- Tapping a customer opens an **Individual** detail screen showing their
  name, email, and balance.
- A **Transfer** screen lets you pick an amount (via +/- buttons or a text
  field) and tap a recipient from the same customer list. Confirming the
  transfer adds the chosen amount to that recipient's in-memory balance
  (there is no sender/source account debited — it's a one-sided demo of
  updating a balance, not a real transfer).

## Features

- Customer list view (`lib/CustomersList.dart` holds the static `name`,
  `email`, and `balance` data used everywhere in the app).
- Customer detail view (`lib/Individual.dart`).
- "Transfer" flow with an amount stepper, a manual amount entry field, a
  recipient list, and a confirmation dialog that updates the recipient's
  balance in memory (`lib/Transfer.dart`).
- Simple branded UI (custom background image, consistent color scheme).

There is no authentication, no database, no network/API calls, and no data
persistence — closing the app discards any balance changes made during the
session.

## Tech stack

- **Flutter** / **Dart** (mobile app framework)
- SDK constraint in `pubspec.yaml`: `>=2.7.0 <3.0.0` (pre-null-safety Dart).
  The code also uses widgets (`RaisedButton`, `FlatButton`) that were
  deprecated and later removed from modern Flutter — see
  [GUIDE.md](GUIDE.md) for the practical implications of this.
- Platform scaffolding for **Android** and **iOS** (generated by
  `flutter create`, largely unmodified).
- No backend, database, or external HTTP APIs.

## Getting started

### Prerequisites

- A [Flutter SDK](https://flutter.dev/docs/get-started/install) install.
  Because this project targets an old, pre-null-safety Dart SDK
  (`>=2.7.0 <3.0.0`) and uses widgets removed in newer Flutter releases, you
  will likely need an older Flutter SDK to run it as-is. See
  [GUIDE.md](GUIDE.md) for details and options.
- A configured Android emulator/device or iOS simulator/device (or a
  desktop/web target enabled in your Flutter install).

### Run it

```bash
git clone https://github.com/Natnael3344/Banking.git
cd Banking
flutter pub get
flutter run
```

### Run the tests

```bash
flutter test
```

Note: `test/widget_test.dart` is the unmodified counter-app template
generated by `flutter create` — it does not test anything in this app and
will fail if run (see [GUIDE.md](GUIDE.md)).
